# List of software packages

This a list of software and tools used for this course.
Take into account that this is just a guide, because the original course is not updated. As you can see the packages version is old. altough, it's still usefull as a guide.


## Short read transcript assembly/gene expression:
    • Psiclass (C code) source
        ◦ V1.0.3 https://github.com/splicebox/PsiCLASS
    • STAR (C code) source
        ◦ 2.7.11b https://github.com/alexdobin/STAR
    • DESeq2 conda env
        ◦ 1.42.1 https://bioconductor.org/packages/release/bioc/html/DESeq2.html
    • Cufflinks/Cuffdiff2 (C code?) offical pre-compiled
        ◦ V2.2.1 https://cole-trapnell-lab.github.io/cufflinks/install/
    • samtools  (C code) source
        ◦ 1.10 using htslib 1.10 https://github.com/samtools/samtools/releases/tag/1.10
    • bedtools (C code) ubuntu package manager
        ◦ V2.31.1 https://github.com/arq5x/bedtools2
    • (sra-tools – on Docker image only) official pre-compiled
